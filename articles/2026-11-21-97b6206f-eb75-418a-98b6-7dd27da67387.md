# 账户表的 JSONB 字段查询与 GIN 索引

<!-- content-workspace-job:97b6206f-eb75-418a-98b6-7dd27da67387 -->

## 问题场景

账户表把扩展属性塞进 JSONB 字段，查询时用 ->> 取值再比较，数据一多就全表扫，接口从几十毫秒涨到几秒。

## 实现步骤

包含关系用 @> 判断，语义清晰且能命中 GIN 索引。

```sql
SELECT id FROM accounts WHERE payload @> '{"credit": 1}';
```

建 GIN 索引，注意操作符类要选对，默认支持包含与存在判断。

```sql
CREATE INDEX idx_credit ON accounts USING GIN (payload);
```

只取个别键时用 ->> 输出文本，需要类型转换就在表达式里显式转。

```sql
SELECT id, payload->>'credit' AS v
FROM accounts WHERE payload ? 'credit' LIMIT 5;
```
