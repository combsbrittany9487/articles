# 奖金推送用 SSE 并在断线后自动重连

<!-- content-workspace-job:726e109f-b4d2-4539-af5f-d10e8429f259 -->

## 问题场景

奖金状态需要近实时更新，轮询开销大且延迟高，直接用长连接又容易在弱网下静默断开。

## 实现步骤

用 EventSource 订阅推送地址，监听 message 事件更新状态。

```javascript
function connect(url, onData) {
  let delay = 1000;
  const open = () => {
    const es = new EventSource(url);
    es.onmessage = (e) => { delay = 1000; onData(JSON.parse(e.data)); };
    es.onerror = () => { es.close(); setTimeout(open, delay); delay = Math.min(delay * 2, 30000); };
    return es;
  };
  return open();
}
```

监听 error，在连接关闭后按递增间隔重建，避免密集重试。

```javascript
const state = { count: 0 };
const es = connect('/api/bonus/stream', (msg) => {
  state.count += 1;
  document.querySelector('#bonus-badge').textContent = state.count;
});
```
