# 审计请求失败时按状态码分流重试

<!-- content-workspace-job:0c8dc6d2-1d42-4e19-b313-74afb1717332 -->

## 问题场景

审计列表接口偶发 502，前端统一无脑重试三次，遇到参数错误时也重试，白白放大流量。

## 实现步骤

把状态码分成可重试与不可重试两类，只有 5xx 与超时进入重试。

```javascript
const RETRY = new Set([502, 503, 504]);
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
```

重试间隔按指数增长并加随机抖动，避免同一时刻大量请求打到同一实例。

```javascript
async function get(url, tries = 3) {
  let last;
  for (let i = 0; i < tries; i++) {
    const res = await fetch(url);
    if (res.ok) return res.json();
    last = res.status;
    if (!RETRY.has(res.status)) break;
    await sleep(300 * 2 ** i + Math.random() * 100);
  }
  throw new Error('audit 请求失败: ' + last);
}
```
