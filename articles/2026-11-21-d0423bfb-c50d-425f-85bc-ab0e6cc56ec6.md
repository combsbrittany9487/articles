# 为报表表的rows统计建覆盖索引消除回表

<!-- content-workspace-job:d0423bfb-c50d-425f-85bc-ab0e6cc56ec6 -->

## 问题场景

报表表的汇总查询只用到rows一列，却每次都回表几百万次，磁盘读放大严重，统计接口常年占着数据库三成负载。

## 实现步骤

确认查询涉及的列，全部放进联合索引，形成覆盖。

```sql
SELECT rows, COUNT(*) FROM reports GROUP BY rows;
```

索引列顺序按等值在前、范围在后排列，最左前缀才用得上。

```sql
CREATE INDEX idx_rows ON reports (rows, id);
```

用 EXPLAIN 的 Extra 列确认出现 Using index，说明没有回表。

```sql
EXPLAIN SELECT rows FROM reports WHERE rows > 5000;
```
