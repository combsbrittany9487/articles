# 事件表按payload查询用不上索引的几种写法

<!-- content-workspace-job:e4061ef8-ae5b-4f37-8996-5d5b5dca76b7 -->

## 问题场景

事件表在payload上明明建了索引，按日期查还是全表扫描。把语句拿出来看，条件里对列做了函数运算，索引自然用不上。

## 实现步骤

定位问题：条件里出现函数、算术运算或类型不一致，索引都会失效。

```sql
EXPLAIN SELECT * FROM events WHERE DATE(created_at) = '2026-01-01';
```

把运算挪到常量侧，改成范围比较，索引就能正常命中。

```sql
SELECT * FROM events
WHERE created_at >= '2026-01-01' AND created_at < '2026-01-02';
```

用 EXPLAIN 确认 type 从 ALL 变成 range，rows 明显下降。

```sql
EXPLAIN SELECT * FROM events WHERE payload + 0 > 4096;
CREATE INDEX idx_payload ON events (payload);
```
